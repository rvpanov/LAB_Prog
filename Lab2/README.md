# Лабораторная работа № 2. Генерация векторных изображений SVG на C++

**Вариантная часть: вариант № 1.** Стандарт: C++17. Используются только средства стандартной библиотеки C++.

## Состав проекта

- `include/SVG.h` — объявления SVGElement, Rect, Circle, Line, Polyline, Path, Group, Transform, градиентов, SVGDocument и SVGDocumentBuilder.
- `src/SVG.cpp` — реализация объектов, валидации, сериализации и сохранения SVG.
- `src/main.cpp` — консольное меню и четыре задания.
- `CMakeLists.txt` — сборка проекта через CMake.
- `examples/` — четыре примера SVG для пунктов меню 1–4.
- `previews/` — соответствующие PNG-визуализации.

## Запуск через терминал Visual Studio Code

Откройте папку `Lab2_SVG_Variant1` через **File → Open Folder**.

При установленном CMake и компиляторе g++ (MSYS2 на Windows) выполните в терминале:

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
.\build\svg_generator.exe
```

Если CMake уже настроен с другим генератором, очистите папку `build` или используйте новую. 
Также можно собрать вручную:

```bash
g++ -std=c++17 -Wall -Wextra -Iinclude src/main.cpp src/SVG.cpp -o svg_generator
```

**Важно:** SVG-файлы сохраняются в текущем рабочем каталоге, из которого запущена программа. Вводить нужно простое имя вида `result.svg`.

## Пункты меню

1. Поворачиваемый прямоугольник: ввод canvas/viewBox, центра, размеров, скругления, угла, сдвига, масштаба и стиля. Используется локальная геометрия `x = cx - w/2`, `y = cy - h/2`, transform с `rotate(alpha,cx,cy)`.
2. Вложенные группы: N >= 2, вложенный `Group` с полиморфным `vector<unique_ptr<SVGElement>>`, повороты, сдвиги и масштабы.
3. Path: команды `M`, `C`, `L`, `Q`, опциональная `Z`, свойства stroke-dasharray, stroke-linecap, stroke-linejoin.
4. Вариант № 1: `linearGradient` с >= 3 остановками (цвет, смещение, прозрачность), координатами градиента, 4 замкнутыми перекрывающимися Bezier Path и общей аффинной матрицей группы.

Предусмотрены проверки числовых вводов, радиусов, координат, цветов `#RGB`, `#RRGGBB`, названных цветов, `rgb(r,g,b)`, прозрачности, остановок градиента и невырожденности матрицы. Программа повторно запрашивает некорректный пользовательский ввод.

## Паттерны

- **Composite:** `Group` хранит дочерние объекты `unique_ptr<SVGElement>`, применяет общий стиль/трансформацию через `<g>` и использует виртуальную `render()`.
- **Builder:** `SVGDocumentBuilder` по шагам собирает параметры страницы, блок `<defs>` и элементы SVG, затем возвращает `SVGDocument`.
- **RAII и глубокое копирование:** `unique_ptr`, `clone()` для полиморфного копирования; копирование `Group` клонирует всех потомков.

## Проверка

Проект собирался g++ с `-std=c++17 -Wall -Wextra -Wpedantic`. Четыре примера SVG прошли проверку XML-структуры и были отрисованы в PNG. Откройте любой файл `.svg` в браузере.

Обратите внимание: `previews/*.png` — визуализация образцов для отчёта. Отдельный письменный отчёт с титульным листом и UML-диаграммой не входит в этот архив.
